# Explainable-PCOS-Detection-from-Ultrasound-Images-Using-Federated-Prototype-Learning
FedProto-US (Federated Prototype learning for Ultrasound) is a federated, intrinsically interpretable framework that combines federated prototype learning with a prototype-based classification head (ProtoPNet) built on a frozen Vision Transformer adapted with Low-Rank Adaptation (LoRA).
